`_run(batch).latency_ms` intervals. This includes tokenization, batch packing,
model/backbone/head, host materialization, decision interpretation and benchmark
row bookkeeping. It excludes source admission, loading, warmup, ownership scans,
quality checks, JSON/file I/O, gaps between calls and HTTP transport/admission

values separately; do not substitute their sum for the canonical metric.

and gaps can affect arrival cadence, governor state and cache behavior even

service-rate diagnostic, not observed unpaced throughput or online capacity.
