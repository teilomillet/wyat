case happens to land on the same side. The FP32 representation of log(4) yields
a true probability slightly below .2; record that returned value rather than
assuming exact mathematical equality. The supplied inclusive lower threshold
still produces false. Do not reinterpret the last array slot as true.

Observe U9 overlap timing: the slow scorer sleeps two seconds, so launch the
second request while the first is executing. If the participant merely sends
sequential requests, admission evidence is missing, not a pass. An observer
infrastructure failure remains an explicit failed trial after assignment.
